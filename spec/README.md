# ensemble-weather-spec

The contract behind every official SDK for the [Ourea](https://oureawx.com)
probabilistic weather API.

| | |
|---|---|
| [`openapi/v1/openapi.yaml`](openapi/v1/openapi.yaml) | The public OpenAPI 3.1 spec for API v1 (generated from the Ourea service; do not edit here). |
| [`BEHAVIOR.md`](BEHAVIOR.md) | What every SDK does: requests, canonical URLs, probabilities, units, errors, retries, caching. |
| [`SDK-STANDARD.md`](SDK-STANDARD.md) | What every SDK repository contains: README, examples, tests, lint, CI, releases. |
| [`vectors/`](vectors/) | Shared test vectors that every SDK's test suite runs. Generated by `scripts/build_vectors.py`. |

## The SDKs

| Language | Repository | Install |
|---|---|---|
| Python | [ensemble-weather-python](https://github.com/Ourea-Technologies/ensemble-weather-python) | `pip install ensemble-weather` |
| TypeScript / JavaScript | [ensemble-weather-typescript](https://github.com/Ourea-Technologies/ensemble-weather-typescript) | `npm install ensemble-weather` |

| Java | [ensemble-weather-java](https://github.com/Ourea-Technologies/ensemble-weather-java) | `com.oureawx:ensemble-weather` |
| Kotlin | [ensemble-weather-kotlin](https://github.com/Ourea-Technologies/ensemble-weather-kotlin) | `com.oureawx:ensemble-weather-kotlin` |
| Swift | [ensemble-weather-swift](https://github.com/Ourea-Technologies/ensemble-weather-swift) | Swift Package Manager |

## Documentation

Guides, concepts and the API reference are at **https://docs.oureawx.com**.

## Working on this repository

```sh
pip install -r requirements.txt
python scripts/build_vectors.py          # regenerate vectors/ after editing the cases
python scripts/build_vectors.py --check  # what CI runs
python scripts/validate.py               # bodies and spec examples against the spec
```

A change to `BEHAVIOR.md` that changes behaviour ships with the vectors that
pin it. A release tag here (`v1.x.y`) is what the SDKs pin in their `spec/`
directory.
